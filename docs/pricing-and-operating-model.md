# 요금·운영 모델 결정안

> **상태: 제안(사용자 결정 필요). 최종 결정이 아니다.**
> 이슈 [#49](https://github.com/littlebit0/DailyPostBox/issues/49)의 결정 사항을 정리한 초안이다. 아래 수치와 경계는 모두 가정이며, 측정 결과와 사용자 결정에 따라 바뀐다.

## 1. 배경

DailyPostBox 서버는 IMAP 계정마다 장기 연결(IDLE)을 유지한다(README "Architecture"). 사용자·계정 수에 비례해 서버 비용이 생기므로 무료와 유료의 경계를 미리 정해야 한다. 현재 운영용 데이터베이스, 비밀정보 저장소, 푸시 제공자는 연결되어 있지 않다. 따라서 비용 수치는 아직 측정된 적이 없다.

## 2. 무료 범위 (제안)

| 항목 | 제안 | 근거와 열린 질문 |
| --- | --- | --- |
| 계정 수 | 무료 3개 | 계정 수가 곧 상시 IMAP 연결 수다. 측정 후 조정한다. |
| 실시간 수신 | 무료에 포함 | 앱의 핵심 가치다. 유료로 막으면 경쟁력이 약해진다. |
| 보관 기간(서버 메타데이터) | 현재 가져오기 옵션(100/500/1,000/전체/미가져오기) 유지 | 서버 저장 비용은 운영 DB 도입 후 재산정한다. |
| 메일 본문 | 서버에 영구 저장하지 않고 조회 시 IMAP에서 가져온다 | 현재 구조 기준이며 저장 정책은 별도 결정이 필요하다. |

결정 필요: 무료 계정 수(3개 vs 다른 값), 실시간 수신을 무료 계정 전체에 적용할지.

## 3. 유료 기능 후보

| 후보 | 비용 성격 | 유료 후보 근거 |
| --- | --- | --- |
| 예약 발송, 스누즈, 후속 알림 | 서버 타이머와 상시 작업 큐 | 사용자가 앱을 꺼도 서버가 동작해야 한다. |
| AI 요약 | 호출당 외부 API 비용 | 사용량에 정비례해 비용이 든다. 호출 한도를 두어야 한다. |
| 자동 분류 | 모델 호출 또는 규칙 처리 비용 | 규칙 기반이면 저렴하고 모델 기반이면 AI 요약과 같다. |

원칙: 서버 비용이 계정 수와 호출 수에 비례하는 기능만 유료 후보로 둔다. 기본 수신·열람·발송은 유료로 막지 않는다. 구독 가격은 이 문서에서 정하지 않는다. 비용 측정 후 결정한다.

## 4. 광고·데이터 판매 금지 원칙 (제안)

- 광고를 넣지 않는다.
- 메일 내용과 메타데이터를 판매하거나 광고·분석 목적으로 제3자에게 제공하지 않는다.
- AI 기능은 사용자가 켠 경우에만 해당 메일 내용을 외부 API로 보낸다. 모델 학습에 쓰지 않는 조건의 API를 우선 검토한다.
- 근거: 무료 앱 Edison이 받은편지함 데이터 활용으로 비판받았다([MacRumors](https://macrumors.com/2020/02/10/edison-mail-responds-to-inbox-data-scraping-report)).
- 확정되면 개인정보 처리방침에 반영한다.

## 5. 자체 호스팅 (제안)

- 서버가 `apps/server`로 공개되어 있고 로컬에서 실행할 수 있으므로, 사용자가 직접 서버를 운영하는 방식을 허용하는 방향을 제안한다.
- 자체 호스팅에서는 유료 기능을 어떻게 다룰지(전부 사용 가능, 또는 AI 키를 사용자가 입력) 결정이 필요하다.
- 공식 서버의 지원 범위는 공식 호스팅 사용자에 한정한다.
- 결정 필요: 라이선스 선택과 자체 호스팅 지원 범위.

## 6. 계정당 서버 비용 요소와 측정 계획

측정할 항목:

| 항목 | 지표 | 측정 방법 |
| --- | --- | --- |
| IMAP 연결 | 계정당 상시 연결 수, 재연결 횟수 | 서버 카운터와 로그 |
| 메모리 | 계정 N개 연결 시 프로세스 RSS | 계정 수를 단계별로 늘려 측정 |
| 푸시 발송량 | 계정당 일일 발송 수 | 푸시 제공자 연결 후 카운터 |
| AI 호출 | 계정당 호출 수, 토큰 수 | 기능 도입 시 호출 로그 |

계획:

1. 서버에 위 지표를 기록하는 최소 계측을 추가한다(별도 이슈).
2. 실제 계정을 여러 개 연결해 계정 수별로 측정한다. 실계정 사용은 사용자 승인 후 진행한다.
3. 측정값을 이 문서에 기록하고 무료 계정 수와 유료 가격을 다시 검토한다.

현재 측정값: 없음.
